# Kirby Operations Hub

The operations console for Kirby's India Global IT Hub: Service Desk, NOC, SOC, cloud and site operations across 22 sites in India, the Middle East and Vietnam. Copilot Studio is the AI and action layer.

- `index.html` is the whole console in one file. Open it in a browser, or publish with GitHub Pages from the `main` branch root.
- Every screen runs live: Command Center, Shift Readiness, Site 360, Tickets & Approvals, Live Operations, Network Graph, Knowledge Graph, Correlation, Observability, SAP Experience, Digital Experience, the nine towers, Site Cutover, Service Performance, Reports, Audit Log, Copilot Studio Agents and the Automation Library.
- Live Demos: the service desk voice agent, IT Help in Teams, and demos for every tower that play end to end with approvals.
- `build/` holds the source and the Kirby data, so any change can be rebuilt (see `build/README.md`).
- `classic/` is the earlier console, kept for reference.

All readings, incidents and people are sample operations data on Kirby's real estate. Not connected to live tools.
